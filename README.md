# 💰 Smart Wallet — Offline-First

Digital wallet na gumagana **kahit walang internet**.
Ginawa para sa Pilipinas — palengke, tindahan, komunidad.

## Mga Tampok
- ✅ Offline QR Payment — bayad kahit walang signal
- ✅ Lokal na pagpapatunay — hindi kailangan ng server sa oras ng bayad
- ✅ Limitasyon sa kaligtasan — hanggang ₱500 bawat bayad, ₱2,000/araw
- ✅ Awtomatikong pag-si-sync kapag may internet na
- ✅ Libre — walang buwanang bayad, walang bawas
